# Arrays

    - Create, access, modify arrays
    - Array methods: push, pop, shift, unshift, splice, slice, reverse, sort
    - map, filter, reduce, find, some, every (intro level)

Common Confusion:
    - splice vs slice
    - map vs forEach
    - sort behavior without compareFn

Mindset:
