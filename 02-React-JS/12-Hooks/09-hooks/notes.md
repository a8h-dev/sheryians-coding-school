# Hooks

-- useState -> state ko manage krne ke liye.

-- useContext -> global state ko consume karne ke liye without prop drilling

-- useReducer -> complex state management ke liye (Redux jaisa chota version).

-- useEffect -> side effects handle krne ke liye (jaise API call, DOM manipulation, event listener).

-- useRef -> mutable values hold karne ke liye jo re-render trigger na karein, ya DOM access krne ke liye.

-- useMemo & useCallback -> optimization ke liye, unnecessary re-renders avoid karne ke liye.
